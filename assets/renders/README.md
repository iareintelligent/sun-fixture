# `assets/renders/`

Per-floor lights-off base renders exported from Sweet Home 3D. One PNG per floor at the canonical aspect ratio decided during the pilot floor work.

Naming: `floor-<id>-base.png` (e.g., `floor-1-base.png`, `floor-b-base.png`).

These are the bottom layer in the Picture Elements stack. Keep them; the masks in `assets/masks/` are positioned against them.
