# `assets/photos/`

Reference photographs of the home, used during Sweet Home 3D modeling and (potentially) Photoshop mask painting. Not for compositing into the dashboard — those come from `assets/renders/` and `assets/masks/`.

Raw camera output (huge files, RAW/HEIC) goes in `raw/` and is gitignored. Curated, cropped, downsized reference shots live at the top level of this directory and are committed.

See `docs/photography-protocol.md` for shooting guidelines once that's populated.
